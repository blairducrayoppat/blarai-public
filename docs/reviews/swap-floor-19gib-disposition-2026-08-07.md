## Note on process

The reviewer's most valuable finding (F1) was not a code defect. It was that the author had written a confident claim about a dataset without reading the dataset — while the entire change was framed as an exercise in claim honesty. The dataset was one directory away. That is the failure mode worth carrying forward, and it is why the journal fragment leads with it rather than burying it.
