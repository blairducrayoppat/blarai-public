# Disposition — #1592 (the operator approved a 200-character view of a query of any length)

**Two passes are dispositioned here.** The first is the RESEARCH the Lead Architect required before
approving a fix — it overturned the fix I had proposed. The second is an adversarial review of the
fix that replaced it, run by an agent that wrote none of it, against `6e7b0fa0` on
`fix/1592-approved-query-is-sent-query`; corrections in `dd7177f2`.

**The verdict in one line: the diagnosis survived, the proposed remedy did not, and of the fix that
replaced it four of six review findings were defects in my own work — including the one this session

## The honest note

This ticket was opened because a control had no production caller for the traffic that actually
leaves this machine. The fix for it shipped a correct mechanism with no production test on its
caller — the same shape, one layer up, found by the review rather than by me. The instrument that
caught it was not a source scan; a source scan cannot tell a `break` from a `continue`. It was a list
of door calls, recorded by a test that drove the real loop twice.
