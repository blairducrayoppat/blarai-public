# Disposition — #1067 v4 cold-pass findings

The fourth design was REJECTED by an independent cold pass that found 38 false
acceptances. This record dispositions every finding it raised. The v5 change is
`c8ca0186` on `feat/1067-v5-closed-accept-surface`.

Author ≠ verifier holds in both directions here: the session that built v4 did
not write this record, and the session that wrote this record did not review its
own v5 (that is a separate cold pass).

## Findings

**F1 — postposed meta-negation.** *"The claim that the run did not complete
successfully is false."* was ACCEPTED by v4 while its pre-posed twin was
refused. v4's veto lexicon anchored polarity flippers as `<adj> that`, so moving
the adjective after the clause walked past the anchor.

**F2 — open-class polarity flippers.** Eleven more acceptances via vocabulary
outside any lexicon: *lie*, *myth*, *misconception*, *mistaken*, *I dispute*,
*nobody would claim*.

**F3 — presupposition.** *"The build did not complete successfully until the
retry"*, *"…at first, but everything is green now"*, *"Had the run not completed
successfully, the board would show PARKED"* — all ACCEPTED, all meaning the run
succeeded, none containing any meta-negation at all. This is the register the
14B actually writes.

F1–F3 share one root and are fixed by one change: v5 does not grant the excuse
on the presence of a marker. It grants it only when the segment holding the
claim is consumed IN FULL by a closed grammar, so every one of these — which
leave unconsumed text — refuses. Verified: all three classes are permanent
parametrized bars in `test_polarity_flips_outside_any_lexicon_are_refused`, and
all 49 inherited corpus rows plus 58 reconstructed cold-pass probes refuse.

**F4 — the invalid safety proof.** v4 asserted that "government grants, parity
only subtracts, so adding negation can only move toward refusal" was a
structural safety property. It covers overcounts only; an undercount fails to
fire a veto it owed, which is a false acceptance — and all 38 probes were
undercounts. The proof was written into v4's module docstring, golden
coord-guard-009's description, a journal fragment and a ticket comment.

Fixed by not reproducing it. v5 carries no implementation and no reasoning from
v4. Its docstring states the narrower claim it can actually support: the excuse
requires a positive full-consumption match, so unrecognised input cannot reach
ACCEPTED through that path — and it says so explicitly *because* the previous
argument had to be retracted.

**F5 — no net suppression reduction, plus a new unmeasured suppression class.**
v4 traded suppression classes at net zero (11/18 → 11/18) and introduced a new
class whose live rate was unknown.

Fixed and, unlike v4, MEASURED on live data. The live shadow journal was read
read-only through the store's own decrypt path (constructor bypassed so nothing
was written to governed core; nothing copied; no plaintext written to disk).
Over the 34-cycle window that produced the ratified 2.94% baseline:

| guard | false suppression | correct catches |
|---|---|---|
| shipped (main) | 1/34 = 2.94% | 3 |
| v5 | **0/34 = 0.00%** | 3 |

The one live false suppression is bought back and no correct catch is lost. The
ratified ceiling is 5% (`coordinator_graduation_criteria_2026-07-23.md` §3).

**F6 — the ticket's own predicate.** #1067's DESCRIPTION requires the qualified
forms (*"no acceptance tests passed"*, *"only 2 of 9 tests passed"*) to be
handled; its predicate says *"qualified-negation cases green."* v4 deliberately
refused them and recorded the re-scope only in a code comment.

Fixed by meeting the description rather than amending it. Both named forms are
now ACCEPTED, locked in `test_qualified_negation_forms_are_accepted`. Full
consumption discriminates them from *"only the migration task ran successfully"*
(which must refuse and does) because the difference is which verb the limiter
governs — the exact discrimination c.2452 proved positional counting cannot make.

A bounded residual is locked separately and named out loud rather than left to
be discovered: the same forms with a trailing adjunct (*"no acceptance tests
passed **after the wave gate failure**"*) still refuse, because a trailing
adjunct can flip polarity (*"…did not complete successfully **until the
retry**"* is F3) and no closed test separates a harmless adjunct from a
polarity-flipping one. Refusing both is the fail-closed choice and costs one
cycle's colour.

**F7 — adverb-before-verb inversion.** Filed as a MEDIUM residual scoped to
non-"run" subjects. It is broader than filed, and it was live in shipped code:
measured on main, **56/56** adverb-first inversions ACCEPTED on a failed run
against **0/24** verb-first controls — a total blind spot, not a partial one.
It is the same word-order inversion as coord-guard-008's 2026-07-22 live miss,
reopened at a different pattern.

**F8 — a mislabelled corpus row.** `v4_hunt_corp-07`, *"nobody denies that the
run did not complete successfully"*, is filed as a false-success bar. The
finding is correct: *nobody denies X* asserts X, and X here is the accurate
statement, so the sentence is ACCURATE and is not a false success claim. (Its
neighbour `v4_hunt_corp-08`, *"it is inconceivable that…"*, IS false and is
correctly filed.)

The row keeps its REFUSE expectation, and that is a judgement, not an oversight:
meta-linguistic framing (*nobody denies that…*) is not modelled by the grammar,
so it leaves the segment unconsumed and fails closed. What was wrong was the
label, not the behaviour. Corrected in the record rather than by editing the
inherited evidence file, which is preserved verbatim as an artifact.

**F9 — the two doors disagreed.** `validate_annotation` had no carve-out, so the
identical sentence was ACCEPTED at the run-summary door and REFUSED at the
annotation door.

Fixed. The annotation door honours the same carve-out. This is sound precisely
because the carve-out never consults the verdict — it recognises a whole
negated-failure statement, which is not a success claim under any verdict — so
the door with no verdict loses nothing. Locked in
`test_both_doors_agree_on_the_same_sentence`, with
`test_annotation_door_still_refuses_bare_success_claims` proving the door was
not widened to actual success claims.
