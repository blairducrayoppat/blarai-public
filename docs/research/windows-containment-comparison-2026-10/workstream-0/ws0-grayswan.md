## 2. Research and artifacts
Papers (READ abstracts via arxiv.org/abs and export.arxiv.org, fetched 2026-10-10; full text NOT read):
- Circuit Breakers, arXiv 2406.04313 (2024-06-06): "circuit-breaking directly controls the representations that are responsible for harmful outputs ... we extend our approach to AI agents, demonstrating considerable reductions in the rate of harmful actions when they are under attack." A model-weight training technique (you must train the model), not a runtime filter.
- Independent criticism, arXiv 2407.15902 (Schwinn et al., 2024-07-22, READ abstract): "by implementing a few simple changes to embedding space attacks ... we achieve 100% attack success rate (ASR) against circuit breaker models" (scope: unconstrained continuous embedding-space attacks).
- AgentHarm, arXiv 2410.09024 (2024-10-11): 110 malicious agent tasks (440 augmented), 11 harm categories; HF dataset ai-safety-institute/AgentHarm, card licence tag "other" (terms not read).
- ART, arXiv 2507.20526 (2025-07-28): "1.8 million prompt-injection attacks, with over 60,000 successfully eliciting policy violations"; "22 frontier AI agents across 44 realistic deployment scenarios"; "Nearly all agents exhibit policy violations for most behaviors within 10-100 queries"; "limited correlation between agent robustness and model size, capability, or inference-time compute, suggesting that additional defenses are needed". Where the ART benchmark is hosted: NOT verified.
- IPI paper, arXiv 2603.15714 (2026-03-16): "464 participants who submitted 272000 attack attempts against 13 frontier models, yielding 8648 successful attacks across 41 scenarios ... attack success rates ranging from 0.5% (Claude Opus 4.5) to 8.5% (Gemini 2.5 Pro)"; settings tool calling, coding, computer use; "We open source the competition environment ... along with 95 successful attacks against Qwen that did not transfer to any closed source model".
- Pen-test comparison (Dec 2025): "purpose-built agents can outperform 90% of human professionals" - vendor research-page summary only, SUMMARY ONLY.
- Also credited on the vendor research page (SUMMARY ONLY, authorship per vendor): RepE, GCG, HarmBench, WMDP, D-REX (2025-09), safety pretraining (2025-04).

## 3. Fit against BlarAI (facts)
(a) OS-level containment of a coding agent on Windows (#1740): none found. Cygnal / Cygnal Code is a text classifier: the pending tool call plus conversation is sent to api.grayswan.ai/cygnal/monitor and scored against a policy; enforcement is by the agent's own PreToolUse hook (cooperative, in-process hook of Claude Code / Codex), not by process token, file ACL or network filter. The agent process keeps whatever OS rights its account has. Docs list Codex and Claude Code only (not opencode); the installer is a bash `curl | bash` plus python3, and there is no Windows statement anywhere in the docs. Shade, Arena, Adversarial Evaluation and Red-Teaming are testing/assessment services, not containment.
(b) Fully local, no data leaving: Cygnal docs show only the hosted endpoint api.grayswan.ai. Marketing says "SaaS, on-prem, or VPC" with no doc, price, artifact or hardware requirement for on-prem; weights unpublished. The vendor's own plugin sends system prompt, full history and prior tool results to the service (the same shape as the hosted judge BlarAI already refused). Local-capable pieces are only: MIT benchmark code and MIT 95-attack dataset (ipi_arena_os, with a vllm provider option), nanoGCG (MIT), circuit-breakers training code (MIT).
(c) Other BlarAI surfaces: (1) Policy-Agent door prompt-injection defence: no runnable local Gray Swan classifier exists; the IPI/ART papers are evidence about attack success against hosted frontier models and state "additional defenses are needed" beyond model capability. (2) Red-teaming local Qwen3-14B: ipi_arena_os has 41 behaviors incl. 15 coding behaviors and 95 attacks generated against Qwen (transfer to Qwen3-14B untested); target can be a local OpenAI-compatible endpoint via base_url; judge/WorldSim LLM also required (local use untested). (3) Offline datasets: ipi_arena_attacks (MIT, jsonl), AgentHarm (HF, licence "other"), ART (location unverified).
